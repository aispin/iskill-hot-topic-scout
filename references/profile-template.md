# hot-topic.profile.md —— 选题画像模板

> 复制本文件到你的工作区根目录，改名 `hot-topic.profile.md`，填完三个必填项即可。
> 本 skill 每次运行都会读它；不填完整也能跑，但筛选精度会下降。

## 必填

- **行业赛道**：（例：AI 工具 / 母婴 / 跨境电商 / 健身）
- **产品/账号定位**：（例：WorkBuddy 效率工具种草号 / 知识口播号）
- **目标人群**：（例：25-35 岁一二线城市职场人，想用 AI 提效但不懂技术）

## 选填（填了筛选更准）

- **内容形式偏好**：（口播 / 情景剧 / 测评 / 图文…）
- **账号调性**：（专业干货 / 毒舌吐槽 / 温暖陪伴…）
- **禁碰话题**：（例：竞品点名、政治、悲剧事件）
- **常驻平台**：（视频号 / 抖音 / 小红书 / B站…）
- **历史爆款参考**：（列 2-3 条自己过往表现最好的选题）
